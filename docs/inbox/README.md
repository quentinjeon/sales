# 📥 채널 판매 데이터 수집함

> **이 시스템을 동작시키려면 여기에 파일을 넣어야 합니다.**
> 현재 코드는 계산 엔진까지 완성되어 있고, **실물 채널 파일이 없어 파서를 못 만든 상태**입니다.

---

## 1. 어디에 넣나요

```
docs/inbox/<기간>/<채널코드>/  ← 여기에 엑셀 파일을 그대로 넣으세요
```

예시:

```
docs/inbox/
├─ 2026-07/
│  ├─ HANBIT/     한빛홈쇼핑_거래상세내역_202607.xlsx      ← 이렇게
│  ├─ SWIFT_FF/    스위프트_풀필먼트_상세_202607.xlsx
│  ├─ MALL21/       몰이십일_정산상세_202607.xls
│  ├─ GOODMKT/    통합몰_주문내역_굿마켓_202607.xls
│  └─ BIDNOW/    통합몰_주문내역_비드나우_202607.xls
└─ 2026-08/  (같은 구조)
```

- 폴더명 `<기간>`은 **`YYYY-MM`** 형식입니다.
- 파일명은 자유입니다. 확장자만 `.xls` / `.xlsx` / `.csv`.
- 채널당 파일 1개. 여러 개면 합쳐서 넣거나 채널을 분리하세요.

**넣은 뒤 바로 확인하세요:**

```bash
python -m app.inbox 2026-07
```

필수 컬럼이 있는지 즉시 진단해 줍니다. 통과하지 못하면 어떤 컬럼이 없는지 알려줍니다.

## 2. ⚠️ 어떤 파일을 받아야 하나요 — 가장 중요한 부분

**「부가세신고내역」이 아니라 「주문건별 상세」를 받아야 합니다.**

지금까지 받은 13개 파일 중 12개가 부가세 신고용 요약본이었습니다.
이 파일들은 결제수단별 분해는 상세하지만 **상품명·수량 컬럼이 아예 없어서**
제품별 이익을 계산할 수 없습니다.

| | 요약본 (❌ 안 됨) | 주문건별 상세 (✅ 필요) |
|---|---|---|
| 행 단위 | 월 1행 | 주문 1건 = 1행 |
| 상품명 | 없음 | 있음 |
| 수량 | 없음 | 있음 |
| 계산 가능한 것 | 총매출만 | 제품·딜별 이익 |

### 채널별 다운로드 경로

## 3. 파일에 반드시 있어야 할 컬럼

| 논리 필드 | 예상 컬럼명 | 필수 |
|---|---|:-:|
| 주문일 | 주문일 / 결제일 / 구매확정일 / 정산일 | ✅ |
| 상품명 | 상품명 / 품목명 | ✅ |
| 옵션명 | 옵션 / 단품상세 / 선택옵션 | ✅ |
| 수량 | 수량 / 판매수량 | ✅ |
| 판매금액 | 판매금액 / 결제금액 / 상품금액 | ✅ |
| 수수료 | 수수료 / 서비스이용료 / 매입수수료 | 선택 (있으면 정확도↑) |
| 취소·반품 | 주문상태 / 취소여부 | 선택 |

> **수수료 컬럼이 있으면 추정 대신 실적값을 씁니다.** 지금은 채널 마스터의
> 요율(한빛홈쇼핑 9.5% 등)로 추정 중이라 대시보드에 「추정」 배지가 붙습니다.

## 4. 파일을 넣은 뒤 개발자가 할 일

```bash
python -m app.inbox 2026-07          # ① 파일이 쓸 수 있는지 진단
```

진단을 통과하면:

1. **컬럼 키워드 추가** — `app/services/ingest.py` 의 `SALES_COLUMNS`
   그 채널의 실제 컬럼명을 논리 필드 키워드에 추가합니다. 형식은 [docs/PRD.md](../PRD.md) §4.3 참고.
2. **파서 구현** — `app/services/ingest.py` (YAML 구동 범용 파서)
3. **상품명 매핑** — 화면 `/mapping`에서 미매핑 큐를 처리 (채널당 20~40건)
4. **검증** — 채널별 합계가 아래 실측 신고액과 ±3% 이내인지 확인

### 검증용 정답지 (2026년 4~5월 실적, 단위 원)

| 채널 | 4월 | 5월 |
|---|---:|---:|
| 한빛홈쇼핑 | 9,831,149 | 17,714,579 |
| 스위프트 풀필먼트 | 7,431,120 | 9,563,700 |
| 몰이십일 | 10,599,030 | 6,878,060 |
| 굿마켓 | 5,455,650 | 5,112,630 |
| 비드나우 | 1,494,060 | 1,653,750 |

**4~5월 파일을 받아오면 이 숫자가 회귀 테스트(T-I1)의 기대값이 됩니다.**
가능하면 7월보다 **4~5월을 먼저** 받아 주세요 — 정답지가 이미 있습니다.

## 6. 자주 묻는 것

**Q. 파일이 여러 달치가 섞여 있어요**
넣어도 됩니다. 파싱 시 `주문일` 기준으로 기간을 나누고, 배치 기간을 벗어난 행은
경고와 함께 제외합니다(PRD §7.5).

**Q. 취소·반품이 포함되어 있어요**
P0에서는 취소 건을 순매출 0으로 처리합니다. 반품 반영은 P1입니다.

**Q. 부가세 포함 금액인가요 별도인가요**
채널마다 다릅니다. `app/seed/data.py`의 `CHANNELS`에 채널별
`vat_basis`가 정의되어 있고, 포함이면 파서가 `÷1.1`로 공급가액을 만듭니다.
새 채널을 붙일 때 이 값을 반드시 확인하세요.

**Q. 파일 대신 API로 받을 수 있나요**
P2 계획입니다. 엔스토어 커머스API, 스위프트 WING API 등. P0는 수동 다운로드입니다.
