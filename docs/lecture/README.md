# 바이브코딩 수업 — 매출 관리 시스템 만들기

엑셀 3장을 넣으면 **월별 제품별 매출**과 **채널별 매출·이익률**을 보여주는 시스템을,
프로그래밍 경험 없는 사람이 AI에게 시켜서 만들어 보는 수업입니다.

---

## 수업 진행 순서

| | 단계 | 자료 |
|:-:|---|---|
| 1 | **목업 데이터 소개** — 상품 DB · 채널 DB · 매출 데이터 · 결과 리포트 | [docs/목업데이터-소개.md](../목업데이터-소개.md) |
| 2 | **화면 보기** — 완성되면 어떤 모습인지 먼저 눈으로 확인 | `mock/index.html` (브라우저로 열기) |
| 3 | **명세 읽기** — AI에게 그대로 붙여넣을 PRD | [docs/PRD.md](../PRD.md) |
| 4 | **직접 만들기** — 8단계 프롬프트를 따라 진행 | [바이브코딩-시작하기.md](바이브코딩-시작하기.md) |
| 4+ | **제작 순서 전체** — 정의부터 git까지 15단계 | [바이브코딩-15단계.md](바이브코딩-15단계.md) |
| 4' | **제작 흐름 전체** — 인풋 → PRD → 목업 → 개발 → git 5단계 | [바이브코딩-5단계-제작흐름.md](바이브코딩-5단계-제작흐름.md) |
| 5 | **검수** — 정답지와 숫자 대조 | `결과예시/` |

**순서가 중요합니다.** 결과를 먼저 보여주고, 명세를 주고, 그 다음에 만들게 합니다.
목표를 눈으로 본 사람과 아닌 사람의 결과물은 완전히 다릅니다.

## 강사용 — 데이터 재생성

세 스크립트를 순서대로 돌리면 인풋·정답지·화면이 전부 다시 만들어집니다.

```bash
python -m app.cli init && python -m app.demo
python docs/lecture/실습데이터_생성.py
python mock/generate.py
```

전부 같은 DB(`data/cecnr.db`)에서 뽑기 때문에 **숫자가 어긋날 수 없습니다.**
시드 데이터(`app/seed/data.py`)를 바꾸면 세 개를 다 다시 돌리고,
`tests/test_calc.py` 의 기대값 표도 재생성해야 합니다 (방법은 그 파일 상단 주석 참조).

## 이 수업에서 가르치는 것

프로그래밍이 아니라 **손익 설계**입니다. 세 가지만 남으면 성공입니다.

1. **원가 = 매입가 × 구성수량** — 구성수량을 빼먹으면 이익이 두 배로 부풀려진다
2. **수수료는 채널마다 다르다** — 6.8%~24.0%. "대충 13%"는 2배 이상 틀린다
3. **미매핑을 버리면 매출이 증발한다** — 파일 합계와 대시보드가 다른 이유를 설명할 수 있어야 한다
