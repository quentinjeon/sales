# Part 1. 이 시스템이 뭔지

## 한 문장

> **엑셀 3장을 넣으면 그 달에 무엇을 팔아 얼마가 남았는지를 제품별·채널별로 보여주는 웹 도구.**

```
📦 제품 데이터   (상품정보)  ─┐
🛒 채널 데이터   (채널정보)  ─┼─→  표준화 · 매핑 · 손익계산  ─→  📊 대시보드 + 📗 결과 엑셀
🧾 매출 데이터   (월별 원장)  ─┘
```

## 데이터 3종의 성격이 다르다

| | 데이터 | 성격 | 갱신 주기 | 없으면 |
|:-:|---|---|---|---|
| ① | **제품 데이터** | 마스터 | 제품 늘 때만 | 원가를 모름 |
| ② | **채널 데이터** | 마스터 | 수수료 바뀔 때만 | 수수료를 모름 |
| ③ | **매출 데이터** | 원장 | **매달** | 계산할 대상이 없음 |

①②는 한 번 만들면 거의 안 바뀝니다. ③만 매달 새로 들어옵니다.
**이 구분이 시스템 설계의 출발점입니다.** 안 나누면 "매달 제품 데이터도 다시 올려야 하나?"로 헷갈립니다.

## 왜 필요한가

셀러가 월말에 모르는 건 매출이 아니라 **남았는지**입니다.

| 문제 | 결과 |
|---|---|
| 채널마다 수수료가 다르다 (6.8%~24%) | "대충 13%" 가정이 2배 이상 틀림 |
| 채널마다 상품명이 다르다 | 제품 단위 합산이 안 됨 |
| 원가·물류비가 매출 화면에 없다 | 매출만 보고 판단 |

## 핵심 개념 — 딜

> **딜 = 채널 × 제품 구성 × 가격 티어 × 기간**

같은 즉석밥 24개입 24,900원인데:

| | 한빛홈쇼핑 (9.5%) | 몰이십일 (13.0%) |
|---|---:|---:|
| 판매가 | 24,900 | 24,900 |
| − 수수료 | 2,366 | 3,237 |
| − 원가 (760 × 24) | 18,240 | 18,240 |
| − 물류비 | 3,000 | 3,000 |
| **= 기여이익** | **1,294 (5.20%)** | **423 (1.70%)** |

**채널만 바꿔도 이익이 67% 차이납니다.** 그래서 손익은 제품이 아니라 딜 단위로 계산합니다.

## 계산식

```
순매출   = 판매금액 (취소면 0)
수수료   = 실적값 우선, 없으면 순매출 × 채널 요율
원가     = Σ(구성 SKU × 판매일 기준 매입가) × 판매수량
물류비   = 채널 배송비 모델 × 판매수량
기여이익 = 순매출 − 수수료 − 자사부담할인 − 원가 − 물류비
마진율   = 기여이익 ÷ 순매출
```

## 결과물

```
총매출 77,667,300원 · 기여이익 5,954,482원 · 마진율 7.67%
적자 딜 3건 · 미매핑 7건(214,300원)
```

"매출 7,766만원"이 아니라 **"손에 남은 건 595만원이고, 이 딜 3개는 팔수록 적자"** 가 나옵니다.

## 0단계 — 준비 (10분)

### 할 일

폴더를 만들고 데이터 3종을 넣습니다.

```
내프로젝트/
├── docs/
│   ├── 01_상품정보.xlsx      ← 제품 데이터
│   ├── 02_채널정보.xlsx      ← 채널 데이터
│   └── 03_매출_2026-07.xlsx  ← 매출 데이터
└── mock/                     ← 4단계에서 씀 (비워둠)
```

### 데이터가 없다면

실습용이 준비돼 있습니다 — `docs/lecture/실습데이터/`
자기 회사 데이터로 하려면 각 채널 어드민에서 **주문건별 상세**를 받으세요.
부가세신고 요약본은 **상품명·수량이 없어서 못 씁니다.**

### ✅ 확인

- 엑셀 3개가 열린다
- 매출 파일에 **상품명 · 수량 · 판매금액 · 주문일**이 있다

---

## 1단계 — 데이터를 먼저 이해한다 (20분)

> ⚠ **이 단계를 건너뛰면 2단계에서 AI가 상상으로 PRD를 씁니다.**

### 할 일

엑셀 3개를 **직접 열어서** 아래를 종이에 적습니다.

| 확인할 것 | 예 |
|---|---|
| 제품이 몇 개인가 | 23종 |
| **매입가가 1개당인가 세트당인가** | 1개당 |
| **구성수량 컬럼이 있는가** | ×24, ×1000 |
| 가격이 몇 단계인가 | 정상가/행사가/특가 |
| 채널이 몇 개, 수수료율 범위는 | 5개 운영, 6.8~24% |
| **매출 파일이 채널마다 컬럼명이 다른가** | 주문일자/결제일/구매확정일 |
| 수수료 컬럼을 주는 채널이 몇 개인가 | 5개 중 2개 |

### 왜 중요한가

**구성수량**을 놓치면 원가가 수십~수백 배 작아집니다.

```
원가 = 매입가 × 구성수량 = 14원 × 1,000개 = 14,000원
구성수량을 빼먹으면        = 14원          ← 1000배 차이
```

전 제품이 흑자로 보이는데 아무도 못 알아챕니다.

### ✅ 확인

- 위 7개 항목에 답할 수 있다
- 주문 한 줄을 골라 **손으로 이익을 계산**해봤다

## 2단계 — ChatGPT로 PRD 초안 (30분)

### 할 일

ChatGPT에게 **왕복하면서** PRD 초안을 만듭니다. 한 번에 받지 않습니다.

### 프롬프트 (라운드 0)

```
너는 데이터 시스템 기획자야. 내가 만들려는 걸 설명할 테니
PRD(제품 요구사항 문서) 초안을 잡아줘. 아직 코드는 짜지 마.

[만드는 것]
엑셀 3장(제품·채널·매출)을 넣으면 그 달의 제품별·채널별 이익을 보여주는 웹 도구

[내가 1단계에서 확인한 것]
- 제품 23종, 매입가는 1개당, 구성수량 컬럼 있음(×2~×1000)
- 가격 3단계: 정상가/행사가/특가
- 채널 5개 운영, 수수료율 6.8%~24%
- 매출 파일은 채널별 시트, 컬럼명이 전부 다름
- 수수료 컬럼은 5개 중 2개 채널만 줌

[계산식]
순매출 = 판매금액 (취소면 0)
수수료 = 실적값 우선, 없으면 순매출 × 채널 요율
원가   = Σ(구성 SKU × 매입가) × 수량
물류비 = 채널 배송비 × 수량
기여이익 = 순매출 − 수수료 − 원가 − 물류비

먼저 나에게 **질문**부터 해줘. 애매한 게 뭔지.
```

### 라운드 1~3 — 심문시키기

```
라운드 1:  초안을 절 단위로 써줘
라운드 2:  아래 엣지케이스를 어떻게 처리할지 나에게 물어봐.
           취소 / 증정품 / 매입가 변경 / 반올림 / 순매출 0
라운드 3:  이 PRD로 개발자가 만들면 어디서 막힐지 지적해줘
```

### 왜 ChatGPT부터인가

코딩 도구는 **파일을 보면 바로 코드를 짜려고 합니다.**
ChatGPT는 파일이 없으니 **개념과 규칙에 집중**하게 됩니다. 생각을 정리하는 단계입니다.

### ✅ 확인

- ChatGPT가 질문을 3개 이상 했고, 거기에 답했다
- **엣지케이스 5개**의 답이 PRD에 적혀 있다
- 초안을 `docs/PRD-초안.md` 로 저장했다

## 3단계 — docs에 다 넣고 PRD를 다시 만든다 ★ (30분)

> **여기가 이 흐름의 핵심입니다.**

### 할 일

```
docs/
├── 01_상품정보.xlsx       ← 실제 데이터
├── 02_채널정보.xlsx
├── 03_매출_2026-07.xlsx
└── PRD-초안.md            ← ChatGPT가 쓴 것
```

이 폴더째로 코딩 도구(Claude Code / Cursor)에 주고 **PRD를 다시 쓰게** 합니다.

### 프롬프트

```
docs 폴더에 실제 데이터 엑셀 3개와 PRD 초안이 있어.

1) 엑셀 3개를 직접 열어서 실제 컬럼명·행 수·값 범위를 확인해줘
2) PRD 초안과 실제 데이터가 어긋나는 부분을 전부 찾아줘
3) 그걸 반영해서 docs/PRD.md 를 다시 써줘

특히 확인할 것:
- 매출 파일의 채널별 실제 컬럼명 (초안의 가정과 맞는지)
- 구성수량이 실제로 몇까지 가는지
- 수수료 컬럼을 주는 채널이 정확히 어디인지

그리고 PRD 마지막에 **검수 기준** 절을 넣어줘.
이 데이터를 다 넣었을 때 나와야 하는 총매출·기여이익·마진율·미매핑 건수.
아직 코드는 짜지 마.
```

### 왜 PRD를 두 번 쓰나

| | ChatGPT (2단계) | 코딩 도구 (3단계) |
|---|---|---|
| 보는 것 | 내 설명만 | **실제 파일** |
| 잘하는 것 | 개념·규칙 정리 | 데이터와 대조 |
| 나오는 것 | 논리적으로 그럴듯한 초안 | **실제와 맞는 명세** |

ChatGPT 초안은 **"채널별 컬럼명이 다를 것이다"** 까지만 씁니다.
코딩 도구는 파일을 열어 **"주문일자 / 결제일 / 구매확정일 / 주문일"** 이라고 정확히 씁니다.

초안 없이 코딩 도구에만 주면 데이터는 맞지만 **왜 그렇게 계산하는지**가 빠집니다.
둘을 합쳐야 완성됩니다.

### ✅ 확인 — 가장 중요

**검수 기준 숫자가 PRD에 박혀 있다.**

```
총매출 77,667,300 · 기여이익 5,954,482 · 마진율 7.67%
미매핑 7건 214,300원 · 적자 딜 3건
```

이게 없으면 나중에 **"다 만들었다"를 판단할 수 없습니다.**
화면이 뜨는 것과 숫자가 맞는 것은 완전히 다릅니다.

## 4단계 — mock 폴더에 HTML 화면 (30분)

### 할 일

코드를 짜기 전에 **정적 HTML로 화면을 그려서 눈으로 봅니다.**

### 프롬프트

```
PRD의 화면 절대로 mock/ 폴더에 정적 HTML을 만들어줘.
동작은 필요 없고 보기만 되면 돼.

숫자는 PRD 검수 기준 값을 그대로 하드코딩해줘.
다크모드도 되게 하고, 각 화면에 서로 이동하는 링크를 넣어줘.

화면:
1) 상품 DB      2) 채널 DB     3) 매출 데이터
4) 대시보드      5) 상세 리포트  6) 화면 목록(index)
```

### 왜 코드보다 화면이 먼저인가

```
HTML 목업 고치기 = 30분
코드 고치기      = 3일
```

그리고 목업을 만들다 보면 **PRD에 빠진 게 드러납니다.**

> "이 표에 마진율 컬럼이 있어야 하는데 명세에 없네" → **PRD로 역류시킵니다.**

### ✅ 확인

- 브라우저로 열어서 **"내가 원한 게 이거다"** 라고 말할 수 있다
- 목업 보다가 **PRD를 고친 게 1개 이상** 있다
- 화면에 적자 딜·미매핑이 보인다 (숨기면 안 됨)

## 5단계 — 개발 (본체)

### 대원칙

> **한 번에 하나. 숫자 확인 없이 다음 단계 없음.**

### 순서와 확인할 숫자

| # | 시킬 것 | ✅ 확인 |
|:-:|---|---|
| 1 | 엑셀 3개 읽어서 행 수만 출력 | 23 / 14 / 3,714 |
| 2 | 채널별 다른 컬럼명을 공통 이름으로 통일 | 5개 시트가 한 표로 |
| 3 | 상품명 → 제품 연결, 실패는 미매핑으로 표시 | **미매핑 7건 / 214,300원** |
| 4 | 주문 한 줄 손익 계산 | **1,294원 / 5.20%** |
| 5 | 전체 합계 | **기여이익 5,954,482원** |
| 6 | 제품별·채널별 집계 | 채널별 표가 PRD와 일치 |
| 7 | 웹 대시보드 (mock 참고) | **적자 딜 3건** |
| 8 | 결과 엑셀 내보내기 | 시트 6장 |
| 9 | **실패 경로** | 아래 참고 |

### 9번을 꼭 하세요 — 다들 건너뜁니다

```
같은 매출 파일을 두 번 올리면 매출이 두 배가 돼. 파일 해시로 막아줘.
파일이 달라도 이미 들어온 주문번호는 건너뛰게 해줘.
다시 계산할 수 있게 '기존 데이터 교체' 옵션도 넣어줘.
데이터가 하나도 없는 상태에서도 모든 화면이 에러 없이 떠야 해.
```

실제로 이걸 안 넣고 같은 파일을 두 번 올린 결과:

```
1회차   총매출  77,667,300원
2회차   총매출 155,334,600원   ← 정확히 2배
```

### 막혔을 때

| 상황 | 이렇게 |
|---|---|
| 에러 | **에러 메시지를 통째로** 붙여넣기. 요약 금지 |
| 숫자가 안 맞음 | **차이 금액**을 알려주기 — "167,574원 차이나" |
| 코드가 안 읽힘 | "한 줄씩 한국어로 설명해줘. 나는 처음이야" |
| AI가 딴 걸 만듦 | "잠깐. 지금은 PRD 5절만 하는 거야" |

### ✅ 완료 조건

```bash
pytest -q                    # 테스트 통과
```
- 빈 DB에 엑셀 3장 → **검수 기준과 완전히 일치**
- 데이터 없는 상태에서도 전 화면이 뜬다
- 같은 파일 재업로드가 **차단된다**
